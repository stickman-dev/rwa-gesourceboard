# RWA GE:Sourceboard

A simple custom widget for RCON Web Admin focused on administering GoldenEye: Source dedicated servers. To use this widget you'll require [RCON Web Admin](https://github.com/rcon-web-admin/rcon-web-admin). There's also a [RCON Web Admin Docker](https://github.com/itzg/docker-rcon-web-admin) if you want to go the container route.

The original project hasn't been supported for sometime now so your mileage may vary in terms of functionality.

## Features

- Execute raw RCON commands
- Quick map switching
- Quick server config loading

## Planned Features

- I'm not totally sure. The original project hasn't been supported for sometime now and this was just a quick thing I knocked together to make changing levels a little easier. Not something I really intend on supporting or expanding but who knows. Hopefully someone else finds this useful.
